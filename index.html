      Three plain CSV files together are your full backup. Restore order that works best: Accounts, then Categories, then Transactions.

      Accounts

      Columns: name,starting_balance,type (type is cash or investment, defaults to cash if left blank). Matching names update the starting balance and type; new names create the account.

      Categories

      Columns: name,kind (kind is expense or income).

      Transactions

      Columns: id,date,kind,account,to_account,category,amount,description
      Rows with an id that already exists update that transaction instead of duplicating it — this is what makes re-importing your own export safe. Leave id blank for new rows. to_account is only used when kind is transfer; leave it blank otherwise (and leave category blank for transfers).
